# 胡氏管乐后台改版

本次改版聚焦乐器品牌官网的日常管理，沿用 Vue、Element Plus 与现有 API。改动位于 `codex/admin-core-redesign` 分支，未推送或部署。

## 信息结构

| 一级入口 | 保留的核心工作 |
| --- | --- |
| 工作台 | 产品总量、产品草稿、待联系咨询、品牌动态；直接进入待办 |
| 产品 | 乐器资料、图片、参数、系列、发布状态与版本历史 |
| 官网内容 | 首页与品牌、新闻动态、艺术家、服务与栏目 |
| 客户咨询 | 试奏、报价、售后、普通咨询、艺术家合作与跟进备注 |
| 素材 | 上传、搜索、分类、分页、引用位置与单个素材删除 |
| 设置 | 自己的账号安全、团队权限、密码重置、备份与操作记录 |

删除旧工作台中的库存估值、转化漏斗、性能监控及重复统计卡片；删除 11 套主题与密度选择；移除素材批量清理、全站替换、手工优化标记等复杂界面。原有业务数据和服务器 API 保留，未执行数据库迁移或线上数据删除。库存与价格字段仍可编辑，避免影响官网已有展示逻辑。

## 交互与视觉

- 统一暖白、浅灰绿和深绿色操作色，建立清晰的侧栏、页标题、筛选区与内容表层级。
- 合并重复新增和发布按钮。产品、新闻、栏目新建时默认草稿；通过发布状态控制是否公开。
- 产品长表单按基础信息、发布、介绍、媒体和参数折叠分组；新闻高级搜索分享字段默认收起。
- 首页配置按首页、其他页面海报、联系信息分类；八个 CMS 集合改用栏目选择器。
- 咨询使用服务器总数与分页，不再只展示第一批记录；跟进备注直接保存，避免重复叠加下一步动作。
- 设置按权限按需加载，不向客服请求团队或日志接口。只读账号不显示写操作。
- 403 不再清除有效会话；401 保持会话失效处理。应用挂载前等待路由初始化，保留刷新后的页面地址。
- 手机采用收起导航、卡片列表和适配屏宽的编辑弹窗；控件使用中文。

## 验证

- `npm test`：9 个测试通过，覆盖服务器角色定义对应的导航、真实 Axios 响应拦截器的 401/403 行为。
- 使用正式域名配置完成后台生产构建、构建产物地址检查和 `check:admin-ui`。
- 浏览器验证产品、新闻、FAQ 草稿新建；手机编辑既有草稿；数据库复核内容、状态及未改字段保留。
- 浏览器验证 21 条咨询的筛选、第二页和跟进备注持久化。
- 实际验证管理员、只读、客服登录；只读无新增/编辑/保存，客服导航仅保留工作台、咨询与设置。
- 素材上传 API 与资源列表联通；已引用素材详情显示引用位置并禁用删除按钮。
- 390px 手机视口无页面横向溢出；产品编辑弹窗宽度 358px；导航与保存支持键盘操作。
- 独立只读复核发现的合作申请字段遗漏、成员弹窗错误遮挡已修复。
- 本次验收创建的 21 条咨询、2 个测试账号、3 条草稿、1 个上传测试文件已清理。已有演示资料及审计记录保留。

未实际变更正式账号密码、2FA、成员角色，未执行备份恢复或历史版本回滚；这些接口沿用现有实现并做静态契约核对。本次属于管理页面升级，不代表此前发现的服务器端安全与备份架构问题已经修复。
