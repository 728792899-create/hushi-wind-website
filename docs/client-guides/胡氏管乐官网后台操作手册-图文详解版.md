# 1 访问后台与登录

## 1.1 登录入口

官网供访客查看；后台用于编辑和管理。请在浏览器中打开后台地址 https://admin.preview.dayouyusd.com/，使用账号 admin 及单独交付的密码。当前后台已取消浏览器首次访问口令，只需填写后台登录表单。

1. 打开后台地址，确认页面显示“登录管理后台”。
2. 在“账号”和“密码”中填写交付信息，注意字母大小写及符号。
3. 如果账号已经启用两步验证，展开“已开启两步验证”，填写身份验证器中的 6 位动态验证码；未启用时无需填写。
4. 点击“登录”，进入工作台。顶部账号区域可进入设置，“查看官网”可打开前台。

## 1.2 当前账号的操作范围

admin 已按站主授权设为超级管理员，可使用产品、官网内容、客户咨询、素材、账号管理、审计、备份等全部后台功能。权限开放不代表敏感操作无需确认；删除、密码重置及维护操作仍按页面提示执行。

权限调整后，先保存未提交内容，再刷新后台，使菜单与账号信息同步。不要在仍有未保存输入时反复刷新。

## 1.3 会话到期与退出

后台空闲会话时限为 30 分钟，单次登录的绝对有效期为 12 小时。页面出现即将退出的倒计时后，可点击“继续使用”；已经过期则需要重新登录。若提示原编辑内容已暂存，应保持当前页面，并使用同一账号重新登录；暂存不等于已保存到服务器，也不能保证关闭或刷新页面后仍可恢复。

操作完成后使用顶部退出登录按钮。账号或密码错误时先核对交付信息，不要持续重复尝试；出现临时锁定提示时，按提示等待或联系站主管理员处理。

## 2.1 通用操作方式

列表可通过关键词、状态或分类筛选；改变筛选条件后，按页面提供的“搜索”“刷新”等按钮更新结果。查看记录时先确认名称，再点击该记录的“编辑”。不同页面的保存按钮和发布方式存在区别，不能把所有“保存”理解为同一种操作。

加载失败时先点击页面提供的刷新或重新加载入口。不要在记录尚未加载成功时用空表单覆盖原有内容。多位管理员同时编辑同一记录时，系统可能提示版本冲突，应先保留输入并核对最新记录。

# 3 素材准备与上传规范

## 3.1 支持的文件

| 类型 | 支持格式 | 使用位置 |
| --- | --- | --- |
| 图片 | JPG JPEG PNG WebP GIF | 产品主图、详情图、封面、头像、首页及页面海报 |
| 文档与压缩包 | PDF ZIP RAR | 下载资料、说明书及资料包 |
| 视频 | MP4 MOV | 使用指南等提供视频字段的位置 |

单个文件上限为页面所示的 20 MB，系统按 20 × 1024 × 1024 字节判断。图片建议控制在 2 MB 内；这是体验建议，不是所有图片必须小于 2 MB 的硬性限制。视频应先在本地压缩，再检查清晰度和声音。

Word、Excel、PPT、SVG、HTML 等不属于当前上传格式白名单。文字资料可整理为 PDF，或将需要交付的多个文件打包为 ZIP 后上传。不要仅修改扩展名冒充支持格式。

## 3.2 上传前的资料检查

1. 确认图片、人物资料和下载文件可供本网站使用，并使用正式确认的产品型号与品牌文字。
2. 图片应主体清楚、方向正确、没有无关水印。海报区域可能裁切边缘，重要人物、标志和文字尽量位于画面中部。
3. 文件名建议包含用途、产品或人物名称及版本，例如“产品名称 主图 202610”或“型号 使用说明 中文 V1”。这是管理建议，不是系统强制命名规则。
4. 上传前检查文件大小；PDF 应可正常打开，视频应可正常播放，压缩包应包含所需文件。
5. 不把账号密码、身份证件、客户联系方式等内部资料当作公开网站附件上传。

## 3.3 上传与发布的关系

素材库是文件存放与复用入口。上传成功只说明文件已进入系统，不代表某个页面已换图，也不代表新闻或产品已经发布。完成上传后，应进入目标内容，选择新文件，按该栏目规则保存或发布，再检查官网。

# 4 上传与整理素材

## 4.1 在素材库上传

1. 进入左侧“素材”。按用途选择“产品素材”“品牌与首页”“艺术家”“新闻活动”“服务资料”或“未分类”。
2. 点击“上传素材”，在“上传到分类”中确认目标分类。
3. 点击“选择文件上传”，可一次选择一个或多个文件。选择后立即开始上传；等待每项完成，不要关闭面板或离开页面。
4. 看到“素材上传成功”后点击“完成”，在列表核对文件。取消待上传任务不会删除已经上传成功的文件。
5. 点击图片查看预览；文档和视频应在实际使用位置进一步验证能否打开或播放。

## 4.2 分类与查找

使用名称、产品或引用位置关键词搜索，并结合图片、视频、文档及引用状态筛选。找不到刚上传的文件时，先清除关键词、切回全部分类和类型，再重新搜索。

需要整理分类时，勾选素材，选择目标分类并点击“移动”。切换筛选或翻页会清空当前勾选，执行前应再次核对选中的文件。

## 4.3 名称与引用位置

素材卡片的“管理”可维护展示名称、命名方式及用途分类。选择“跟随引用”时，系统根据当前内容引用生成名称；选择“自定义名称”则按填写的名称显示。展示名称和分类调整不会更改底层文件地址。填完后点击“保存设置”。“替代文字”可用于补充识别说明，但不会自动改写官网所有位置的图片说明。

在“引用位置”中检查文件用在哪里。当前内容、修改草稿、历史版本和回收站均可能保留引用。卡片“更多”中可复制地址；需要填写附件地址时可使用该功能，但必须复制对应文件的完整地址。

## 4.4 在表单中直接上传

产品、艺术家及配置等表单中的图片框也可直接上传图片。已有图片时，点击图片区域选择新文件；带有“从素材库选择”的字段可复用已有图片。只有等待上传完成并保存或发布当前内容后，页面引用才会更新。

# 5 替换图片与清理旧素材

## 5.1 替换一张现有图片

1. 先上传新图片，或确认新图片已在素材库中。
2. 按下表进入目标内容的编辑页，找到对应图片字段。
3. 点击“从素材库选择”，搜索并选中正确图片；也可以在该字段直接上传。选择窗口默认按当前栏目分类筛选，找不到图片时改为“全部分类”。
4. 确认表单中的缩略图已变为新图片。需要先审核效果时，保存修改草稿并预览。
5. 完成发布或直接保存，再打开官网对应页面检查。只替换一个字段不会自动替换其他位置的同一张图。

| 要替换的位置 | 后台入口 |
| --- | --- |
| 产品主图及详情图 | 产品 → 对应产品 → 编辑 |
| 艺术家图片 | 官网内容 → 艺术家 → 对应记录 → 编辑 |
| 首页主视觉及品牌配图 | 官网内容 → 首页与品牌 |
| 新闻封面 | 官网内容 → 新闻动态 → 对应新闻 → 编辑 |
| 服务资料与指南封面 | 官网内容 → 服务与栏目 → 对应栏目 → 编辑 |
| 艺术家 音响 支持页海报 | 官网内容 → 首页与品牌 → 其他页面海报 |

## 5.2 素材库清理

先完成新内容发布，再检查旧文件的引用位置。仍被当前内容、草稿、历史版本或回收站引用的文件，系统会禁止删除。不要仅为清理图片而删除有价值的历史记录。

素材文件删除属于永久删除，不能通过内容回收站找回。只有确认文件不再需要、不存在引用，并保留必要备份后，再进入素材“管理 → 删除素材”，在确认框核对对象并点击“删除”。内容记录删除与素材文件删除的恢复能力不同。

当前素材页面不提供“一键替换全站所有引用”的操作按钮。多处使用同一旧图时，应逐一编辑对应内容并检查发布结果。

# 6 新增产品与维护产品资料

## 6.1 新增产品

进入“产品 → 新增产品”。名称、页面地址、分类名称、产品品类为必填项。页面地址仅使用小写英文字母、数字和分隔短横线，不以短横线开头或结尾、不连续使用短横线。可点击“生成”辅助填写，但应自行核对结果；已有产品的页面地址不能在表单中修改。

| 资料区域 | 填写与核对要点 |
| --- | --- |
| 基础信息 | 主图、名称、页面地址、系列、分类名称、产品品类；确认型号与归属 |
| 价格与发布设置 | 库存量、零售价不得小于 0；确认发布状态及首页推荐选项 |
| SEO 与简介 | 填写简介并检查搜索展示预览；此表单没有独立 SEO 标题输入框 |
| 产品详情 | 参数、核心特性、适用场景、保修说明；只填已经确认的正式资料 |

参数每行填写“参数名：参数值”，例如“调性：降 B 调”；中英文冒号均可，示例不代表任何现有产品规格。缺少名称或数值的行会被过滤。核心特性、适用场景每行一条。选择品类时，只有空白参数区域才会填入模板，已有参数不会被自动覆盖。

资料未完成时设为“草稿”，点击“保存产品”；选择“已发布”时，按钮为“发布到官网”。新记录先保存，再重新编辑，才可使用完整的修改草稿与预览流程。库存与价格字段是产品资料，不构成订单、支付或出入库管理系统。

## 6.2 产品主图与详情图集

主图可直接上传或从素材库选取。“主图加入详情图”会把当前主图加入图集，“清除主图”清除表单引用。详情图集可“批量上传详情图”，也可粘贴有效图片地址后点击“添加”；相同地址不能重复加入。

拖动图集中的图片调整顺序，使用“设主图”“替换”“删除”处理单张图片。“清空图集”只移除该产品图集中的引用，不会永久删除素材文件。所有调整都须保存或发布产品才会生效。

## 6.3 分类与系列

分类与系列用于统一产品归属；乐器分类还可维护参数模板。先确定分类名称、系列名称和顺序，再创建产品；已有产品只换图片时，无需调整目录。

“乐器分类”和“产品系列”可直接切换：选中“产品系列”后，列表显示系列记录，表单显示“所属分类”。分类的参数模板仅在“乐器分类”下维护。切换前先保存正在编辑的内容；若有未保存内容，请按提示决定保留编辑或放弃后切换。

1. 在产品编辑页点击“分类与系列”，打开“产品分类与系列”。
2. 选择“乐器分类”或“产品系列”。新增时在“新增记录”区域填写；修改已有项目时先点击对应记录的“编辑”。
3. 填写“名称”“显示顺序”。名称最多 80 字；显示顺序为非负整数。乐器分类另有“参数模板（每行一个参数名称）”，最多 30 项，每项最多 80 字；产品系列没有参数模板字段。
4. 新分类还须填写“英文标识”，长度为 2 至 40 个字符，以小写字母开头，其后可使用小写字母、数字或短横线。已有分类标识不能修改。
5. 新增系列时填写“名称”，选择“所属分类”，设置“显示顺序”后点击“保存”。编辑系列时先点击该行“编辑”，核对后保存；需要继续新增时点击“新建另一条”。
6. 保存成功后核对列表中的名称、分类标识和顺序；关闭后重新打开确认记录。返回产品编辑页，选择对应品类与系列，核对参数后再保存产品。

正在被产品使用的分类或系列不能删除；类别下仍有系列时也不能删除。已有产品使用的系列不能直接移到另一类别，应先由负责人确定调整方案，不用删除重建来绕过系统限制。

目录保存直接生效，不走修改草稿流程。系列改名可能同步关联产品与支持资料，保存前核对影响范围。修改参数模板不会追溯更新已有产品参数，已有记录需要逐项检查。

## 6.4 产品展示核对

新增产品后检查官网列表和详情页，确认分类、系列、图片顺序、参数和发布状态。勾选“首页推荐”不保证进入首页固定位置，应以官网实际结果为准。对外资料未完成时保留草稿，避免将未核准的型号或参数发给客户。

# 7 修改已发布产品

## 7.1 推荐的修改流程

1. 在“产品”列表搜索目标产品，核对名称和型号后点击“编辑”。
2. 调整主图、详情图、介绍或参数。只修改此次需要变更的内容。
3. 点击“保存修改草稿”。已发布产品的主按钮默认采用修改草稿方式，暂存修改不会立即覆盖官网。
4. 在“修改草稿与预览”区域使用“预览已保存内容”，核对图片和文字。
5. 确认后点击“发布修改草稿”，按弹窗提示确认。
6. 打开普通官网产品页面，确认最新内容已生效。

## 7.2 直接更新官网

已发布产品提供“直接更新官网”的操作入口，确认后会直接发布此次变更。只有不需要暂存或预览时才使用；执行前检查图片、参数和发布状态。不要把它与“保存修改草稿”混淆。

## 7.3 撤回错误修改

尚未发布的修改草稿不会覆盖当前正式内容，可在核对后继续编辑或使用“放弃草稿”。已发布的错误修改，应在产品编辑页查看历史版本，确认目标版本后恢复，再检查官网效果。

恢复历史版本可能同时改变图片、文案、参数及其他字段，不能把恢复理解为只撤回最后一个输入框。已经失效的分类或系列关联按系统规则处理，恢复后应重新核对产品归属。

## 7.4 删除产品

产品删除会移入内容回收站。确需停止展示但保留记录时，将状态设为“隐藏”并点击“保存产品”。不要使用“发布修改草稿”执行下线，该操作会将记录设为已发布。执行删除前应核对产品名称，并检查相关下载资料、指南及其他内容是否仍需关联该产品。误删后在“设置 → 回收站”恢复，具体流程见第 18 章。

# 9 新闻动态发布

## 9.1 新增新闻

1. 进入“官网内容 → 新闻动态”，点击“新增新闻”。
2. 填写必填的“标题”“栏目分类”“发布日期”。分类直接输入文字；发布日期用于展示，不是定时发布开关。
3. 在“封面与正文”中上传“新闻封面”，填写“正文详情”。此页面没有单独的摘要输入框。
4. 按需要填写“搜索与分享设置”：SEO 标题、SEO 描述、关键词和分享图。不填分享图时使用封面；关键词用英文逗号分隔。
5. 首次建议设为“草稿”并点击“保存新闻”，重新打开记录后，保存修改草稿、预览并发布。
6. 在官网新闻列表和详情页检查标题、封面、段落、日期及手机阅读效果。

## 9.2 正文图片与视频

正文为文本编辑区。“正文格式助手”提供“插入小标题”“插入引用”“上传图片插入”“上传视频插入”。助手将内容追加到正文末尾，插入后可自行调整位置。媒体标记应单独占一行；只有上传文件而未插入正文，不会显示在新闻中。

支持以下简单格式。图片和视频地址须替换为实际上传得到的地址；也可直接使用格式助手生成。

```text
## 小标题
### 次级小标题
> 引用内容
![图片说明](/uploads/example.jpg "图片说明")
@[video](/uploads/example.mp4 "视频说明")
```

正文支持普通段落、小标题、引用及上述媒体标记，不是完整富文本编辑器。不要粘贴任意 HTML、复杂表格或一般链接语法并期待自动渲染为相同效果。

## 9.3 保存与发布

编辑已发布新闻后直接点击“保存新闻”，会更新官网。需要审核时应使用“保存修改草稿 → 预览已保存内容 → 发布修改草稿”。表单中的“发布预览”卡片不能代替完整官网核对。

需要撤下新闻时，改为“隐藏”并普通保存；恢复错误编辑可查看历史版本，删除记录则进入回收站。正式发布前须确认人物姓名、日期、图片来源和正文完整，不能把空正文或占位文案当作正式新闻。

# 10 艺术家资料维护

## 10.1 新增展示档案

1. 进入“官网内容 → 艺术家”，点击“新增艺术家”；修改现有资料时搜索姓名、乐器或使用设备，再点击“编辑”。
2. 上传“艺术家照片”，或通过“从素材库选择”选用已有图片。
3. 填写必填的“姓名/艺名”“头衔/乐器”。使用当事人或项目负责人已经确认的称谓。
4. 填写“个人简介”和“使用设备”。简介最多 500 字；使用设备为文字资料，不是产品选择器。
5. 设置“发布状态”和非负的“排序权重”，数值较小的记录在前。
6. 点击“确认保存”，等待成功提示。未确认的资料先保存为草稿，完成核对后再发布。

## 10.2 修改或替换图片

打开目标记录，替换照片或修改字段。需要先检查效果时点击“保存修改草稿”，再“预览已保存内容”，确认后“发布修改草稿”。直接点击“确认保存”会按记录当前状态保存；如果仍是已发布，官网会随之更新。

只修改素材库中的名称不会更换人物图片。换图时应核对人物身份、图片清晰度及不同屏幕上的裁切效果，同时检查姓名、头衔与照片是否对应。

## 10.3 公开展示检查

“前台预览”和列表“预览”打开官网艺术家集合页。当前后台不提供独立艺术家个人详情页、个人相册或单独的英文名输入框；资料应填写在现有字段中。

发布后核对姓名、头衔、简介、使用设备、照片和排序。临时撤下时设为“隐藏”并普通保存；删除记录进入回收站。人物履历、荣誉、合作关系和照片应以获准公开的资料为准。

# 12 下载资料与使用指南

## 12.1 上传可下载资料

1. 进入“官网内容 → 服务与栏目 → 下载资料”，点击“新增内容”或编辑现有记录。
2. 选择 PDF、ZIP 或 RAR 文件上传。上传成功后，系统会填入文件地址和显示大小；名称与类型仍需自行填写。
3. 填写名称、类型、版本、语言、发布日期等适用信息，确认与附件内部内容一致。
4. 按适用范围关联产品或系列，设置顺序和发布状态。
5. 保存或发布后，在官网支持页及相关位置点击下载，检查文件能否打开、是否为正确版本。

更新说明书时，上传新的附件并替换目标记录中的地址。相同文件名不意味着覆盖旧文件；旧附件也不会因为上传同名文件而自动更新。

## 12.2 维护视频指南

进入“使用指南”，填写标题、时长和品类，配置封面图片及视频。页面中的视频上传按钮虽然标为“上传 MP4 视频”，实际支持 MP4 和 MOV，单个文件仍不得超过 20 MB。

视频时长需要按实际内容填写，不会因上传自动生成。保存后在前台检查封面、视频播放、声音、时长描述及手机访问效果。文件存在不等于每种浏览器都能播放；无法播放时可重新导出常用兼容格式后上传。

## 12.3 链接与公开访问核对

附件应使用系统返回的文件地址。不要填写本机磁盘路径、后台页面地址或已失效的临时链接。发布后建议在未登录后台的浏览器窗口中打开公开下载入口，确认普通访客可以获取资料。

本系统不将上传的资料自动排版为网页，也不会自动替换已分散在其他内容中的旧附件链接。相同资料引用多处时，应逐处核对。

# 13 修改草稿与正式发布

## 13.1 分清三种状态

“记录状态为草稿”表示该条内容尚未按正常发布方式公开；“修改草稿”表示对已有记录另存一份待发布修改；“已发布”表示正式内容。修改草稿与记录的发布状态不是同一个概念。要临时下线，选择“隐藏”后使用普通保存；不要用“发布修改草稿”执行隐藏。

| 操作 | 结果 |
| --- | --- |
| 保存修改草稿 | 暂存当前表单，不立即覆盖正式内容 |
| 加载修改草稿 | 将已保存草稿加载到当前编辑表单 |
| 重新获取最新草稿 | 刷新服务器草稿信息；不会自动替换当前表单 |
| 预览已保存内容 | 查看服务器已保存内容或草稿，不包含未保存输入 |
| 发布修改草稿 | 经确认应用草稿；产品、新闻、艺术家及栏目内容会设为已发布 |
| 放弃草稿 | 删除待发布草稿；执行前确认不再需要其中修改 |

## 13.2 普通保存按钮的区别

已发布产品的主操作默认保存修改草稿，并另有“直接更新官网”。新闻“保存新闻”、艺术家“确认保存”、栏目“保存内容”按当前状态直接保存；全局配置“保存并发布”直接更新配置。因此需要先预览时，应主动选择“保存修改草稿”，而不是任意点击普通保存按钮。

## 13.3 预览与多人编辑

预览链接最长有效 15 分钟，内容变动也可能使旧链接失效。失效后回到编辑页获取最新状态，保存需要预览的修改，再生成新预览。列表“预览”或“查看已发布页面”通常打开普通前台页面，不能代替修改草稿预览。

遇到“其他管理员已更新”或“修改草稿已变化”，先复制保留未提交文字，再获取最新记录并核对合并。不要连续点击保存试图覆盖他人的修改；也不要未经核对就加载草稿替换当前表单。

# 14 客户咨询与艺术家合作

## 14.1 跟进客户咨询

进入“客户咨询 → 客户咨询”，按关键词、跟进阶段及类型查找记录。当前 admin 为超级管理员，可处理全部咨询和分配负责人。

1. 点击目标行“查看 / 跟进”；手机端点击“查看详情”，进入“咨询详情与跟进”。
2. 核对客户需求，确需联系时点击“查看联系方式”。联系方式默认隐藏，查看操作会记录审计。
3. 选择跟进阶段与优先级，指定负责人，按需要填写“下次跟进时间”“乐器序列号”。
4. 填写“本次跟进记录”和“内部汇总备注”，点击“保存跟进”。保存成功会关闭面板、更新记录并标记已读；只打开详情不会标记已读。
5. 在工作台检查待联系、到期回访提醒，按照真实进展继续记录。

跟进阶段为“待联系、已联系、已报价、处理中、已完成、已关闭”；优先级为“普通、高、紧急”。咨询类型包括预约试奏、咨询报价、售后维修和普通咨询。阶段表示处理进展，不自动生成订单或收款结果。

本次跟进记录最多 4,000 字。填写新记录或改变阶段会形成跟进时间线；其他字段变更仍留有操作审计，但不一定新增同类时间线条目。负责人仅能选择启用中的超级管理员或客服。客服只处理分配给自己的咨询，不能自行认领未分配事项或重新分配。

<!-- sectionbreak -->

## 14.2 处理合作申请并建立艺术家档案

1. 切换到“艺术家合作”，查找申请人并点击“查看申请”。按需查看联系方式和“查看作品集”。
2. 将申请状态设为“待审阅、已跟进、已通过、未通过”中的实际结果，点击“保存跟进”。
3. 需要建立公开档案时，先保存“已通过”，再重新打开申请，点击“建立艺术家草稿”，确认“建立档案”。
4. 系统创建艺术家草稿后，进入“官网内容 → 艺术家”，补齐照片、公开简介、头衔和使用设备，再预览发布。

同一申请已有档案时不重复创建。转建不会把私人联系方式或完整申请正文自动公开。申请详情没有咨询页的负责人、回访计划及内部备注字段。

## 14.3 联系方式与隐私

同一账号在 10 分钟内合计查看咨询及合作申请联系方式达到 30 次，系统产生告警，不因该阈值自动阻断；审计写入失败时不会返回联系方式。客户咨询页没有批量导出个人信息、新建咨询或删除咨询的操作入口。

# 15 账号安全与团队权限

## 15.1 修改密码

进入“设置 → 账号安全”，填写当前密码、新密码及确认新密码，点击“更新密码”。生产密码要求为 12 至 64 位，并同时包含大写字母、小写字母、数字和符号。修改后需要重新登录，其他旧会话也会失效。

## 15.2 设置两步验证

1. 在“账号安全”的“两步验证”区域点击“设置两步验证”。
2. 在身份验证器中添加账号，选择输入设置密钥，并录入页面提供的密钥。
3. 填写验证器显示的 6 位动态验证码，点击“验证并启用”。
4. 后续登录展开“已开启两步验证”并填写动态码。关闭两步验证同样需要有效动态码。

设置密钥应单独妥善保存，不放入网站素材库或本手册。更换手机前先安排验证方式转移；无法提供动态码时联系站主或维护人员处理，不反复尝试登录。

<!-- sectionbreak -->

## 15.3 团队与权限

进入“设置 → 团队与权限 → 新增成员”，填写账号、显示名称、初始密码、角色和状态，再点击“保存成员”。账号为 3 至 32 位字母、数字、下划线或短横线；默认角色是只读观察员，应按实际职责选择。

已有成员点击“管理”，可调整显示名、角色和启用状态，账号名不能编辑。需要重置他人密码时展开“重置登录密码”，输入合规新密码，点击“重置密码”并确认。旧会话随即失效，但不会关闭该账号的两步验证。

| 角色 | 主要权限范围 |
| --- | --- |
| 超级管理员 | 全部后台权限；当前 admin 属于此角色 |
| 运营管理员 | 产品、内容、配置、素材及日志、告警、备份；无团队及 CRM 管理权限 |
| 内容编辑 | 新闻、服务栏目及素材上传；产品、艺术家、首页只读 |
| 客服 | 处理分配给自己的咨询及现有合作申请流程 |
| 只读观察员 | 查看获准的数据和日志，不能替代编辑角色 |

不能修改当前登录账号自身的角色或启用状态，也不能停用或降权最后一个启用的超级管理员。账号名称 admin 的停用另有备份、其他超管、操作者两步验证及确认要求；这不是普通客户停用流程，需要维护人员配合。

# 16 设置栏目与运行信息

设置包括以下八个标签。当前 admin 具有全部后台权限；其他账号按角色显示相应功能。

| 栏目 | 主要用途 |
| --- | --- |
| 账号安全 | 修改本人密码，启用或关闭两步验证 |
| 回收站 | 恢复已删除的内容记录 |
| 团队与权限 | 新增成员，管理角色、启用状态及重置密码 |
| 数据备份 | 查看备份、创建备份和演练恢复 |
| 操作记录 | 筛选操作记录，校验审计完整性 |
| 安全告警 | 查看告警并标记处理状态 |
| 通知投递 | 查看投递状态，安排失败任务重试 |
| 维护记录 | 查看近期自动任务与执行结果 |

## 16.1 安全告警

进入“安全告警”，点击“刷新告警”，查看时间、级别、标题、说明和状态。级别包括严重、错误、警告、提醒；状态为待处理或已处理。根据说明解决原因后，再点击“标记已处理”。该按钮只改变记录状态，不会自动修复网络、磁盘、备份或账号问题。

## 16.2 通知投递

查看通知类型、状态、尝试次数和失败原因。具备条件的失败或待重试记录可点击“重试”，出现“已安排重试”后，稍后重新查看状态；排队不代表收件人已经收到。

本页不用于配置接收地址或新增通知渠道。未配置通知渠道时可能没有任务记录，不能据此判断系统故障；也不代表已经启用短信或邮件服务。

## 16.3 自动维护记录

进入“维护记录”，点击“刷新维护记录”，检查周期审计、自动备份、留存清理等任务。已完成、失败、进行中或尚未完成应分别识别；进行中不等于通过。当前页面展示最近 20 条记录，更早记录由维护人员核查。

后台没有修改维护计划、备份保留天数或服务器配置的表单。遇到运行故障，记录标题、时间、说明后联系维护人员，不自行操作同机其他服务。

# 17 操作记录 审计与数据备份

## 17.1 查看操作记录

进入“设置 → 操作记录”，按操作人、栏目、开始日期和结束日期筛选，点击“筛选”；点击“刷新”获取最新记录。列表用于核对时间、操作人、栏目及操作描述。当前页面没有独立的登录记录入口；需要查询实际登录成功或失败记录时，由维护人员核查。

点击“校验记录完整性”，等待“校验通过，共 N 条记录”等结果，并核对校验时间、历史基线和新记录信息。结论对应此次核验快照，不代表所有业务内容已审核无误。校验失败时保留错误与时间，联系维护人员处理，不删除或重签历史记录来消除提示。

当前页面没有日志导出按钮；需要提供审计资料时，由维护人员按授权范围执行。操作审计与其他运行记录的留存规则不同，不应将所有日志理解为永不清理。

<!-- sectionbreak -->

## 17.2 创建备份

1. 进入“设置 → 数据备份”，查看已有备份及演练状态。
2. 重要批量修改前点击“创建备份”，在确认框点击“创建”。
3. 等待完成，确认“创建结果”为“已创建”；必要时点击“刷新备份”。
4. 记录备份标识和时间，以便后续定位。此操作创建服务器数据库与本地素材副本，不会自动下载到自己的电脑。

服务按实际维护配置执行自动备份与留存清理。页面不能修改执行周期或保留天数；备份失败应联系维护人员核查原因，不能只因点击过按钮就认定资料已安全留存。

## 17.3 验证备份能否恢复

对已经成功创建的备份点击“演练恢复”，等待完成，再按需“刷新备份”。该按钮点击即发起演练。结果包括尚未演练、演练进行中或未完成、演练通过、演练失败；只有完成结果才代表此次检查结论。

成功摘要可查看快照时间、表数、素材数、审计条数、审计续写和耗时。演练在独立副本中验证，不覆盖当前网站，也不会让官网回到历史版本。创建成功和演练通过是两项不同检查。

## 17.4 整站恢复与迁移

真正恢复当前数据库、搬运备份、建立异地副本或迁移服务器，由维护人员执行。当前页面没有上传备份、下载备份、删除备份或一键覆盖线上数据的入口。同机备份不能单独应对整机或整盘损坏。

迁移应携带客户最新内容数据库与对应素材，不能用最初展示资料覆盖后续上传内容。内容历史、回收站和备份的适用范围见下一章。

# 18 历史版本与回收站

## 18.1 选用正确的恢复方式

| 遇到的问题 | 使用入口 | 核对重点 |
| --- | --- | --- |
| 已编辑内容不符合预期 | 内容编辑页的历史版本 | 恢复目标版本中的整份内容及关联字段 |
| 内容记录被误删 | 设置 → 回收站 | 恢复正确对象，并核对恢复后的发布状态 |
| 未发布的调整不再需要 | 修改草稿区域 | 清除或重新编辑修改草稿，不误改正式内容 |
| 素材文件已永久删除 | 联系维护人员检查备份 | 内容回收站不能恢复素材文件 |
| 数据库或服务器异常 | 维护人员恢复流程 | 数据库与素材需成套恢复 |

## 18.2 恢复历史版本

打开目标内容的编辑面板，进入“历史版本”，按时间、内容及操作信息确定需要恢复的版本。核对后执行页面提供的恢复或回滚操作并确认。恢复前保留正在编辑的重要输入，恢复后核对图片、文字、发布状态及关联产品。

历史版本恢复可能覆盖多个字段，不是简单撤销某一步输入。若分类、系列或其他关联已发生变化，恢复后应重新核对；不要连续恢复多个版本来试错。

## 18.3 恢复回收站记录

进入“设置 → 回收站”，在列表核对内容名称、类型及删除时间，找到目标后点击“恢复”并确认。恢复后回到原栏目检查记录，并在官网核对展示情况。恢复可能带回原先的发布状态，不一定变成草稿；务必核对是否已经重新公开。

## 18.4 无法删除旧图片

图片仍可能被修改草稿、历史版本或回收站记录引用。此类引用用于保护内容恢复能力。应先在素材“管理”中查看引用位置，再决定是否确有清理需要；不要为了释放一个文件而删除仍有价值的历史数据。

# 19 常见问题与处理方法

| 问题表现 | 处理方法 |
| --- | --- |
| 素材上传后官网未变化 | 进入对应内容选用新素材，并完成保存或发布；仅上传不会换图 |
| 已保存修改草稿但官网未更新 | 先预览，再执行“发布修改草稿” |
| 选择图片时找不到素材 | 清除关键词并切到全部分类；图片选择器不会显示文档或视频 |
| 文件上传失败 | 核对格式与 20 MB 上限，检查网络及登录状态，再按报错处理 |
| 上传按钮仍在等待 | 等上传完成后再保存；不要离开页面重复提交 |
| 预览链接过期 | 返回编辑页，获取最新状态并重新生成预览 |
| 记录已被其他人修改 | 保留输入，加载最新记录核对合并，避免覆盖他人更新 |
| 官网仍显示旧图片 | 先确认已发布且改的是正确字段，再刷新目标页面并核对其他引用位置 |
| 权限或菜单未更新 | 保存未提交内容后刷新后台，必要时退出后重新登录 |
| 页面要求再次登录 | 按提示重新登录；出现暂存提示时保持原页面并使用同一账号 |
| 页脚版权字段保存后没变化 | 当前官网页脚为固定显示，需维护人员修改模板 |
| 删除素材被拒绝 | 查看当前内容、草稿、历史版本和回收站中的引用 |
| 演练恢复成功但官网没回滚 | 演练只校验隔离副本，真正恢复由维护人员处理 |

## 19.1 提交问题时提供的信息

记录后台栏目、目标记录名称、操作时间、错误提示、是否已保存或发布，以及能否稳定重现。需要截图时尽量保留按钮与提示，但不要把密码、验证码密钥或客户联系方式包含在截图中。

涉及保存结果不确定时，先重新读取目标记录确认服务器实际状态，再决定是否再次提交；不要连续点击保存、上传、删除或重试通知。

## 产品系列切换与保存后如何核对

点击“产品系列”后，应看到选中的标签、系列列表及“所属分类”字段。若浏览器仍停留在旧界面，先保存已有编辑，再刷新后台并重新打开“分类与系列”；出现未保存提示时先处理提示，不要重复点击。保存系列后重新打开目录核对名称、所属分类和顺序，再回到产品表单选择该系列并保存产品。若仍异常，记录页面提示、操作时间与截图后联系维护人员；不要删除分类后重建。

# 20 日常维护清单与交接要求

## 20.1 每次发布前

- 确认编辑的是正确产品、人物或栏目，正式文字及素材已经确认。
- 图片上传已完成，附件地址、关联产品、排序及发布状态正确。
- 已区分普通保存和修改草稿，需要预览的修改已经保存并预览。
- 下载文件可打开，视频可播放，链接指向正确页面。

## 20.2 每次发布后

- 打开普通官网页面，检查修改已生效，而不是只查看后台缩略图。
- 电脑与手机各检查一次图片裁切、文字阅读、按钮及下载效果。
- 检查同一素材在其他页面的引用是否需要同步替换。
- 记录较大内容调整的时间与范围；必要时确认成功备份已经留存。

## 20.3 定期维护

根据实际业务安排检查待联系咨询、到期回访、合作申请、失败通知及未处理告警。定期确认备份成功状态和恢复演练记录，清理前先核对素材引用，不以删除历史记录作为日常空间管理方法。

团队成员变更时核对账号角色与启用状态；只向获准人员交付账号资料。多人使用时，可由超级管理员按实际职责建立独立成员账号，以便区分操作记录。

## 20.4 迁移与交付

服务器或域名迁移应由维护人员统一安排，并携带当前最新的内容数据库、上传素材及必要配置。客户上传新资料后，不应重新导入最初展示包覆盖现有内容。迁移完成后，重新检查登录、上传、主要页面、下载、联系方式及备份。

需要日常操作指引时，可从“设置 → 使用帮助”查找对应指南。本手册版本如与后续界面发生差异，应以更新后的交付说明为准。
