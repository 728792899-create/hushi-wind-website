# 已知边界

本地实现、测试、CI 与生产验收分开记录；当前未生产部署。完整准入项目和待决策事项见 [生产准入清单](production-readiness.md)。

- 公开版本使用虚构品牌数据和开源许可素材，不包含生产数据库、客户资料或临时上传文件。管乐真实内容、授权图片与真实联系方式待用户提供和验收；合成图片对比度不能外推到真实素材。
- 当前为单进程 SQLite 与本地素材目录。RBAC 已覆盖超管、内容编辑、客服、只读及客服咨询归属，未承诺复杂组织、多租户或多实例。共享限流、对象存储/CDN 等按实际需求决定，不默认采购。
- 会话、逐条联系方式审计、并发版本、审计链、周期核验、告警去重及完整备份恢复已完成本地验证；本地链不能抵御特权者整链重写、整库回滚，也不能证明历史基线前真实性。外部可信锚点和异地不可变留存未接入。
- 本地三档容量及正常 SIGINT/SIGTERM 排空已有证据；真实磁盘/负载、大于 2 GiB 文件恢复、生产管理器宽限期、强杀/断电恢复与业务 RPO/RTO 未验收。4 GiB 大小元数据往返不等于真实文件恢复。
- 根目录 Quality 流水线覆盖测试、构建、依赖与产物审计；安全发布脚本有门禁和回滚保护。未启用自动生产发布，真实域名/TLS、PM2、权限、通知与人工登录/MFA仍需获准后的现场验收。
- 官网 6 项工具链审计例外仍以 2027-01-09 为原到期日，不自动延期。产物来源图与摘要未签名，生成代码归因与函数可达性有限制，不能称完整供应链证明。
- 390/1440 浏览器检查已覆盖公开站和后台相应页面；真实手机、屏幕阅读器及正式素材的最终验收仍待补。
